# Сайт o-dio.design

Сайт студии o'dío. Общаемся по-русски, тексты на сайте на английском. Стратегия, решения и структура сайта описаны в репозитории `d0nLino/odio-studio-growth`, файл `site.md`.

## Устройство

- Статичный сайт без сборки, все файлы сайта в папке `public/`. Настройки деплоя — `wrangler.jsonc`. Без фреймворков; когда появятся страницы кейсов, переходим на Astro.
- **Кейсы** — список в `public/js/cases.js`. Порядок в списке = порядок в сетке. Клик по карточке открывает модальное окно; ссылка `o-dio.design/#<id>` открывает кейс сразу (для писем).
- **Медиа** — в Cloudflare R2 (`https://media.o-dio.design/`), папка = id кейса. В `cases.js` пишется путь внутри хранилища. В репозиторий фото и видео кейсов не кладём.
- **Хостинг** — Cloudflare Workers (статичные файлы), проект `odio-site`, деплой командой `npx wrangler deploy` после каждого push в `main`. Без сборки.

## Ветки

- `main` — то, что открывается на o-dio.design. Сейчас там заглушка по макету Figma (секция 1432:3503: компьютер 1425:3330, телефон 1429:3465): белый фон, синее свечение сверху, плашки, фирменный шрифт OT Neue Montreal Medium Squeezed (`public/fonts/`). Отправлять в `main` только по команде основателя: клиенты видят сразу.
- `funnel` — обложка с 3D-воронкой на прокрутке (в работе). Закрыта от поисковиков (`noindex`, `robots.txt`). Смотреть: https://funnel-odio-site.dionis-7b9.workers.dev (предпросмотр ветки Worker `odio-site`).
- `full-site` — одностраничник с сеткой кейсов и модальными окнами (черновик).

## Медиа: требования

- Фото: WebP, ширина 2400 px для обложек и галереи, до ~400 КБ.
- Видео-лупы: MP4 (H.264), без звука, 5–15 секунд, до ~5 МБ, плюс постер (первый кадр, WebP).
- Обложки 4:3.

## Как добавить кейс

1. Загрузить медиа в R2 в папку `<id>/`.
2. Добавить запись в `public/js/cases.js`.
3. Проверить локально: `python3 -m http.server -d public` и открыть http://localhost:8000.
